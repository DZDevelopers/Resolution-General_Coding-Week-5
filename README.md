# Resolution-General_Coding-Week-5

This was made for [Resolution General Coding](https://resolution.hackclub.com/app/pathway/general_coding), a [Hack Club](https://hackclub.com/) YSWS.
It’s fully open source, and you’re free to use it however you like.

This is a C program that can read content from a CSV file and create one with the content you want.
It include 4 commands

h - help; It shows all the commands.

a - Add a new contact; it creates a CSV file with the contact you added.

l - List all contacts; it reads all the CVS files in the current folder and displays the content.

q - Quit; It quits the program.
